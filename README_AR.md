# Kennedy AI — نسخة جاهزة للرفع إلى GitHub وRender

## مهم قبل البدء
هذه النسخة تربط الواجهة بخادم Python وتتحقق من ملف الصورة، لكنها **لا تحتوي على نموذج ذكاء اصطناعي مدرّب**. لن تعطي تصنيف Kennedy I–IV أو نسبة ثقة حتى تتوفر بيانات صحيحة ويُدرّب النموذج ويُختبر. لا تستخدمها لاتخاذ قرارات طبية ولا ترفع صور مرضى حقيقية في هذه المرحلة.

## هل أحتاج إلى تثبيت Python على جهازي؟
لا. تستطيع رفع الملفات من متصفحك إلى GitHub، ثم تربط المستودع بخدمة Render ليتم تثبيت الاعتماديات وتشغيل Python على الخادم.

## طريقة النشر المجانية مبدئياً
1. أنشئ حساباً على GitHub: https://github.com/
2. أنشئ مستودعاً جديداً باسم `kennedy-ai`، واجعله Public إن كنت لا تحتاج إلى مستودع خاص، ثم أنشئه.
3. داخل المستودع اختر **Add file → Upload files**.
4. ارفع محتويات هذا المجلد كلها (لا ترفع ملف ZIP نفسه فقط): `app.py`, `index.html`, `requirements.txt`, `render.yaml`, `README_AR.md`، ومجلد `static` كاملاً وفيه `style.css` و`script.js`.
5. اضغط **Commit changes** لحفظ الملفات.
6. أنشئ حساباً على https://render.com/، ثم اختر **New → Blueprint** إن ظهر الخيار، واربط حساب GitHub والمستودع `kennedy-ai`. سيقرأ Render ملف `render.yaml`.
7. اختر الخطة المجانية إن كانت متاحة لحسابك ومنطقتك، ثم أنشئ الخدمة وانتظر انتهاء النشر.
8. افتح رابط الخدمة الذي ينتهي بـ `onrender.com`. جرّب رفع صورة اختبار غير حساسة. سيؤكد الموقع صلاحية الملف وأبعاده، ولن يصدر تصنيفاً بعد.

إذا لم يظهر خيار Blueprint، اختر **New → Web Service**، اربط المستودع، وحدد:
- Runtime: Python
- Build Command: `pip install -r requirements.txt`
- Start Command: `uvicorn app:app --host 0.0.0.0 --port $PORT`
- Instance Type: Free (إذا كان متاحاً)

## فحص الخادم
افتح `https://YOUR-SERVICE.onrender.com/api/health` بعد استبدال `YOUR-SERVICE` باسم خدمتك. يجب أن تظهر استجابة JSON فيها `"status":"ok"` و`"model_ready":false`.

## قيود الخطة المجانية
قد يدخل الخادم في وضع السكون عند عدم الاستخدام، وقد يتأخر أول طلب بعد الخمول. كما يمكن أن تتغير شروط الخطة المجانية. لا تفترض أن الاستضافة المجانية مناسبة لتطبيق طبي إنتاجي.

## ملفات المشروع
- `index.html`: الواجهة العربية.
- `static/style.css`: التصميم.
- `static/script.js`: معاينة الصورة وإرسالها للتحقق.
- `app.py`: خادم FastAPI ونقطة التحقق `/api/predict`.
- `requirements.txt`: المكتبات التي يثبتها الخادم.
- `render.yaml`: إعداد نشر Render.
